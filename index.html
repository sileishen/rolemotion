Project Overview

四层技术架构
One Connected System

RoleMotion 不以单一模型为终点，而是围绕统一动作表示连接采集、生成、评价与机器人执行。 每一层都有清晰输入输出，也保留可回放、可检查和可复用的工程节点。

L01

Data Foundation

Motion Capture、Xsens Data Check 与 UE5 Retarget 组成真实动作数据入口。

L02

Motion Intelligence

统一 20 FPS / 135D 表示，为 StableMoFusion 的训练与推理提供标准数据。

L03

Human-aligned Evaluation

以 Match 与 Smooth 为核心维度，把人的动作感知纳入自动评价体系。

L04

Embodied Deployment

GMR、HoloMotion、Isaac Lab 与 Unitree G1 共同完成 Sim2Real 闭环。

Inspect Every Stage
