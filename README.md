# RoleMotion Pipeline

RoleMotion 的项目主页，展示从 motion capture、motion processing、text-to-motion 到 simulation 与 Unitree G1 deployment 的完整链路。

在线访问：<https://sileishen.github.io/rolemotion/>

## Website structure

- `index.html`：页面结构与内容
- `style.css`：视觉样式与响应式布局
- `script.js`：导航、图片预览与 Technical Details 交互
- `assets/`：项目图片与 teaser

The site is published with GitHub Pages from the `main` branch.
